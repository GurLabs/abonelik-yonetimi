# 💳 Abonelik Takibi ve Ödeme Yönetimi (Subscription Tracker)

**Abonelik Takibi**, aylık ve yıllık tekrarlayan ödemelerinizi, deneme sürelerinizi (Free Trial), fatura tarihlerini ve iptal adımlarını kontrol altında tutmanızı sağlayan modern, minimalist ve %100 açık kaynaklı bir web uygulamasıdır.

![Abonelik Takibi](https://gurlabs.com)

---

## ✨ Öne Çıkan Özellikler

- 🔔 **Abonelik İptal Hatırlatıcısı ve Rehberi (Cancellation Assistant):** Deneme süreli (Free Trial) veya yakında iptal etmek istediğiniz abonelikler için hatırlatıcı alarm kurma ve popüler servisler (Netflix, Spotify, Adobe, ChatGPT, Amazon Prime vb.) için **tek tıkla doğrudan abonelik iptal sayfasına yönlendirme rehberi**.
- 📅 **Takvim ve Ödeme Geçmişi Görünümü:** Tüm ödemelerinizi takvim üzerinde görselleştirin ve ay ay hangi ödemeyi yapıp yapmadığınızı (Ödendi / Bekliyor) takip edin.
- 🎯 **Aylık Bütçe Hedefi & Aşım Uyarısı:** Belirlediğiniz aylık bütçe limitini aştığınızda otomatik görsel uyarı alın.
- 🌗 **OLED True Black Koyu Mod:** Gerçek siyah OLED ekran dostu koyu tema desteği.
- ☁️ **Firebase & Gerçek Zamanlı Senkronizasyon:** Google hesabınızla giriş yapabilir veya verilerinizi anında buluta yedekleyebilirsiniz.
- 📊 **CSV Dışa Aktarma:** Abonelik listenizi tek tıkla Excel/CSV formatında indirin.
- 🔒 **Gizlilik Odaklı:** İster anonim misafir olarak ister Google Auth ile kullanın.

## 🚀 Hızlı Başlangıç

 projenizi klonlayın ve bağımlılıkları yükleyip dev sunucuyu başlatın:

```bash
# Projeyi klonlayın
git clone https://github.com/GurLabs/abonelik-yonetimi.git

# Proje dizinine gidin
cd abonelik-yonetimi

# Bağımlılıkları yükleyin
npm install

# Geliştirici sunucusunu başlatın
npm run dev
```
